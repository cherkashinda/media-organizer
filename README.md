# Media Organizer

Инструмент для сортировки семейного фотоархива по папкам **Год → Месяц → Фото/Видео**.

Поддерживает Google Takeout (ZIP-архивы с JSON-метаданными), Live Photo с iPhone,
определение дат из EXIF, метаданных видео и имён файлов, поиск скриншотов и дубликатов,
запись дат обратно в EXIF.

---

## Возможности

Приложение состоит из шести вкладок:

| Вкладка | Описание |
|---|---|
| **📊 Статистика** | Сканирует папку и ZIP-архивы, выводит количество и размер по каждому формату |
| **🗂 Сортировка** | Раскладывает фото и видео по папкам `Год/Месяц/Фото` и `Год/Месяц/Видео` |
| **📅 Карта архива** | Показывает количество файлов и объём по годам и месяцам в отсортированном архиве |
| **📱 Скриншоты** | Находит скриншоты в отсортированном архиве и переносит их в `Скриншоты/` |
| **🔍 Дубликаты** | Ищет одинаковые файлы (размер → MD5) и позволяет удалить лишние копии |
| **✍ Запись EXIF** | Берёт дату из Google JSON (`photoTakenTime`) и записывает её в EXIF JPEG |

Общее: тёмная и светлая тема (переключаются кнопкой), индикатор установленных библиотек
в заголовке, журнал с батчингом вывода — интерфейс не подвисает на больших архивах.

### Опции сортировки

- **Режим:** копировать или перемещать. При перемещении исходник удаляется только после
  проверки, что размер копии совпадает
- **Источники:** обрабатывать видео, заглядывать внутрь ZIP-архивов, удалять ZIP после
  успешной обработки (только если не было ошибок)
- **🧪 Dry Run** — тестовый прогон: показывает, куда попадёт каждый файл, ничего не перемещая
- **Если файл уже есть:** пропустить / перезаписать / создать копию (`имя_copy_1.jpg`)
- **Потоков:** количество параллельных потоков; пауза и продолжение во время работы
- **Источник даты** — показывать в журнале, откуда взята дата
- **Переименовать по дате** — `IMG_1234.jpg` → `2023-06-09_16-36-52.jpg`
- **Фильтр по годам** — обрабатывать только файлы с датой в диапазоне «с … по …»
- **Метаданные Google Takeout** — читать дату из `.json` сайдкаров
- **Пропускать скриншоты** при сортировке
- **Дата файла как резерв** — использовать mtime, если больше ничего не найдено (ненадёжно)
- **💾 Экспорт лога** — сохранить журнал сортировки в файл

### Дубликаты

Сначала файлы группируются по размеру, MD5 считается только для совпадающих по размеру.
Область поиска: только медиа / только фото / все файлы. Результат — дерево групп
(сортируется по колонкам). Можно удалить выбранные файлы или автоматически оставить
первый файл в каждой группе.

### Запись EXIF

Для каждого JPEG ищется Google JSON; дата из него записывается в `DateTimeOriginal`,
`DateTimeDigitized` и `DateTime`. Опционально создаётся резервная копия `.bak`.
Требует `piexif`.

## Определение даты (приоритет)

1. **Google Takeout JSON** — `photoTakenTime.timestamp` из `.json` сайдкара (самый точный).
   Учитываются обрезанные и изменённые Google имена JSON (`.supplemental-metadata.json`, `(1)` и т.п.)
2. **Live Photo** — для видео берётся дата парного `.HEIC` / `.JPG` с тем же именем
3. **Метаданные видео** — MP4 `mvhd` atom, затем `mutagen`, затем EXIF
4. **EXIF (exifread)** — `DateTimeOriginal` / `DateTimeDigitized` (RAW, HEIC, JPEG)
5. **EXIF (Pillow)** — резервный способ для JPEG/TIFF
6. **Имя файла** — шаблоны вида `20230615_142233`, `2023-06-15 14.22.33`, `20230615`
7. **Дата изменения файла** — только если включена опция «Дата файла как резерв»
8. **ZIP metadata** — для файлов из архива: дата записи в ZIP (последний резерв)
9. **`_Без даты/`** — если дату определить не удалось

## Определение скриншотов

Файл считается скриншотом, если:

- Имя начинается с: `Screenshot_`, `Screen Shot`, `Снимок экрана_`, `Скриншот_`,
  `Bildschirmfoto`, `Captura`, `Schermata`, `Capture`
- **ИЛИ** файл `.png` с разрешением, совпадающим с экраном телефона
  (iPhone, Android — более 20 популярных разрешений)

Вкладка «Скриншоты» работает по уже отсортированному архиву: ищет в папках `Фото/Видео`
и переносит (или копирует) найденное в соседнюю папку `Скриншоты/`.

## Поддерживаемые форматы

**Фото:** `.jpg` `.jpeg` `.png` `.gif` `.bmp` `.tiff` `.tif` `.heic` `.heif`
`.webp` `.raw` `.cr2` `.nef` `.arw` `.dng` `.orf` `.rw2` `.pef` `.srw`

**Видео:** `.mp4` `.mov` `.avi` `.mkv` `.m4v` `.3gp` `.wmv` `.flv` `.mpg` `.mpeg`

**Архивы:** `.zip` (Google Takeout и другие; кириллические имена внутри ZIP читаются корректно)

## Аудит дат: `date_audit.py`

Консольная утилита для диагностики — когда непонятно, почему файл получил ту или иную дату.
Для каждого медиафайла (включая содержимое ZIP) выводит в CSV все найденные варианты даты:
EXIF (exifread и Pillow), MP4 `mvhd`, mutagen, Google JSON, дату из имени файла,
mtime/ctime, а также итоговую лучшую дату и её источник.

```bat
python date_audit.py "D:\Фото архив" [output.csv]
```

Если путь к CSV не указан, файл `date_audit_ГГГГММДД_ЧЧММСС.csv` создаётся рядом со скриптом.
CSV в UTF-8 с BOM и разделителем `;` — открывается в Excel без настройки.

## Установка и запуск

### Требования

- Python 3.10 или новее
- Windows / macOS / Linux

### 1. Установка зависимостей

```bat
pip install -r requirements.txt
```

### 2. Запуск

```bat
python main.py
```

---

## Сборка .exe для Windows

### Установка PyInstaller

```bat
pip install pyinstaller
```

### Сборка (один файл, без консоли)

```bat
pyinstaller --onefile --windowed --name MediaOrganizer main.py
```

Готовый `.exe` появится в папке `dist/`.

### Сборка с иконкой

```bat
pyinstaller --onefile --windowed --name MediaOrganizer --icon icon.ico main.py
```

### Если что-то не работает в EXE

Иногда PyInstaller не подхватывает скрытые зависимости. Полная команда с явным указанием:

```bat
pyinstaller ^
  --onefile ^
  --windowed ^
  --name MediaOrganizer ^
  --hidden-import=PIL._tkinter_finder ^
  --hidden-import=exifread ^
  --hidden-import=mutagen.mp4 ^
  --hidden-import=piexif ^
  --collect-all exifread ^
  --collect-all mutagen ^
  main.py
```

### Альтернатива: папка вместо одного файла

Запускается быстрее (нет распаковки при старте):

```bat
pyinstaller --onedir --windowed --name MediaOrganizer main.py
```

Результат в `dist/MediaOrganizer/` — копируй всю папку целиком.

## Зависимости

| Библиотека | Назначение | Обязательна |
|---|---|---|
| `exifread` | EXIF из HEIC, RAW, JPEG | Нет, но без неё RAW/HEIC без даты |
| `Pillow` | EXIF из JPEG/TIFF, размер PNG для скриншотов | Нет, но желательна |
| `mutagen` | Метаданные из MP4/MOV | Нет, есть резервный способ (mvhd) |
| `piexif` | Запись дат в EXIF JPEG | Только для вкладки «Запись EXIF» |

Программа работает и без этих библиотек — просто меньше файлов получат дату.
Какие из них установлены, видно в заголовке окна.

## Часто задаваемые вопросы

**В журнале много `[нет даты]` — почему?**

Вероятно, файлы без EXIF и без Google JSON. Проверь, что галочка «Метаданные Google Takeout»
включена и JSON-файлы лежат рядом с медиафайлами. Чтобы увидеть, какие даты вообще есть
у файлов, запусти `date_audit.py`.

**Видео попадают в дату загрузки, а не съёмки**

Для Live Photo с iPhone JSON создаётся только для фото (.HEIC), не для видео (.MOV).
Убедись, что HEIC и MOV с одинаковым именем лежат в одной папке в ZIP — тогда программа
найдёт дату автоматически.

**Файл оказался в `_Без даты/` — как исправить?**

Открой файл в любом просмотрщике с поддержкой EXIF (FastStone, XnView) и посмотри
дату вручную. Если дата есть визуально, но не в EXIF — возможно, метаданные повреждены.
Можно также включить «Дата файла как резерв», но mtime часто равен дате копирования.

**Хочу проверить результат до перемещения файлов**

Включи 🧪 Dry Run — в журнале будет видно, куда попадёт каждый файл, но на диске ничего
не изменится.

**EXE не запускается — ошибка про DLL**

Установи [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe).
